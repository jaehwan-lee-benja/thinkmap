이번 세션의 작업을 돌아보고, 장기 기억으로 남길 가치가 있는 것을 큐레이팅한다.

## 절차

### 1. 세션 다이제스트 작성 (이 단계는 메인 세션인 네가 직접 한다 — 너만 대화 맥락을 본다)
지금까지의 대화를 훑어 다음을 사실 위주로 정리한다. 각 항목에 근거가 된 발화/결정을 함께:
- **사용자 정체성·선호** 가 드러난 부분 (user)
- **작업 방식 피드백** — 내가 한 일에 대한 교정/확인. 반드시 "왜"까지 (feedback)
- **진행 중 작업·결정·제약** 중 코드·git으로 유추 불가한 것. 상대 날짜는 오늘({{today}}) 기준 절대 날짜로 (project)
- **외부 리소스·문서 경로** (reference)
- 코드/git/CLAUDE.md에 이미 남는 것은 다이제스트에서 제외 (큐레이터가 또 거른다)

### 2. memory-curator 에이전트 호출
위 다이제스트를 **그대로 프롬프트에 담아** memory-curator 서브에이전트를 실행한다. (에이전트는 대화를 못 보므로 다이제스트가 유일한 입력이다.) 에이전트는 기존 memory/와 대조해 선별하고, memory 파일·MEMORY.md를 직접 작성/갱신한 뒤 보고한다.

### 3. 결과 검토 및 CLAUDE.md 적용
- 에이전트의 "저장함 / 건너뜀" 보고를 사용자에게 요약해 보여준다.
- 에이전트가 **CLAUDE.md 제안**을 냈다면: 변경 초안을 사용자에게 보여주고, 동의하면 적용한다(적극적 협업 — 단 적용 전 1회 노출). 거절하면 적용하지 않는다.

### 4. 마무리
무엇을 저장/갱신했고 무엇을 왜 건너뛰었는지 한눈에 요약한다. 별도의 상태 파일은 만들지 말고 채팅 메시지로만 보고한다.

## 호출 시점 가이드
의미 있는 작업(기능 완료, 중요한 결정, 반복되는 함정 발견, 사용자 피드백 수령) 직후 또는 세션을 마무리할 때 실행한다. 새로 추가할 게 없으면 "저장할 것 없음"으로 끝내도 된다.
