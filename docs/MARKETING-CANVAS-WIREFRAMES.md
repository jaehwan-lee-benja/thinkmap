**상호작용**
- 영역(◯) 클릭 → 우측 사이드 영역 패널 열림 (W3)
- 카드(▣) 클릭 → 원본 토글로 점프
- 카드 우클릭 → 상태 변경 / 매핑 해제 / 다른 영역으로 이동
- 우측 토글 풀의 항목을 영역으로 드래그 → 매핑 생성
- 뷰 토글 (Canvas / Board / List) — Phase 1 은 Canvas만, 나머지는 비활성

**필요 데이터 (v0.3 모델 검증)**
| UI 요소 | 데이터 출처 |
|---|---|
| 영역(◯) 위치/이름 | `canvas_schemas.regions` |
| 노드(●) 위치/이름 | `canvas_schemas.regions[].nodes` |
| 영역 안 카드 | `canvas_mappings.region_key = X` |
| 카드 제목 | `blocks` 토글 본문 또는 `pages.name` |
| 카드 상태 (색) | `canvas_mappings.status` + `canvas_workflows` |
| 더보기 카운트 | `count(*) - 표시한 N` |
| 진단(정체/공백) | `canvas_region_stats` view |
| 토글 풀 (우측) | `daily_blocks` + `pages`(general) — 미매핑 항목 |

## W5. 마스터 ↔ 직원 뷰 전환

GlobalTopBar 우측 상단의 모드 토글 (impersonation 시스템과 정합):

```
[마스터 ▼]   ← 마스터 뷰 (전체 카드, 전체 수정)
   ├ 마스터로 보기  ◉
   ├ ──────────────
   ├ 김00 으로 보기      ← effectiveSession 임퍼소네이션
   ├ 박00 으로 보기
   └ 이00 으로 보기
```

**직원 뷰 시 변화**
- 카드 표시: `assignee_id = effective_user_id` 만 (또는 본인 작성)
- 매핑 생성/수정: 본인 카드만
- 양식·워크플로우 편집 메뉴: 숨김
- 페어 생성/삭제: 숨김
- 진단 패널: 본인 카드 기준 통계

**구현**: 기존 `effectiveSession` 활용. RLS는 `is_master()` / `is_linked_account()`로 자동 분기.

## W6. 업무일지에서의 역참조 표시

업무일지 토글 옆 작은 아이콘으로 매핑 위치 표시:

```
┌──────────────────────────────────────────────────────────────┐
│ 5/10 업무일지                                                 │
├──────────────────────────────────────────────────────────────┤
│ ▾ 오전 작업                                                   │
│   ▢ 작마클방법론 정리                          🎯×2  ⓜ        │ ← 🎯 = 캔버스 매핑 카운트
│     │   호버: ┌─────────────────────────┐                     │
│     │         │ 매핑된 곳:                │                     │
│     │         │ • 작마클 캔버스 / 행동    │                     │
│     │         │ • 작마클 캔버스 / 핵심역량│                     │
│     │         └─────────────────────────┘                     │
│   ▢ 콘텐츠 발행체계                            🎯×1            │
│   ▢ 미팅 준비                                                 │ ← 매핑 없음
│ ▾ 오후 작업                                                   │
│   ▢ 자문 미팅 1                                🎯×1            │
└──────────────────────────────────────────────────────────────┘
```

**상호작용**
- 🎯 아이콘 클릭 → 매핑된 캔버스/영역으로 점프
- 다중 매핑이면 호버 시 리스트, 클릭 시 첫 번째로 점프 (또는 선택 메뉴)

**필요 데이터**
- 토글당 매핑 카운트: `canvas_mappings GROUP BY source_block_id`
- 클라이언트 hook: `useCanvasMappingsForBlocks([blockId])`

## 데이터 모델 검증 결론

W1 ~ W6 모든 화면이 요구하는 데이터가 v0.3 모델에 **모두 존재함**.

추가 발견 사항 (v0.3 → v0.4 보강 후보):
1. **카드 정렬**: `sort_order INTEGER` 이미 있음 ✓
2. **정체 감지**: `updated_at` 기반 stalled_n 통계 뷰 이미 있음 ✓
3. **출처 분포**: source_block_id vs source_page_id로 group by 가능 ✓
4. **🎯 아이콘 카운트 쿼리**: `idx_cm_block` 인덱스로 빠름 ✓
5. **(NEW)** Canvas Schema 의 nodes 영역별 그루핑 — 현재 regions[].nodes 로 들어가 있음 ✓

**v0.3 모델 그대로 Phase 1 진입 가능.**
