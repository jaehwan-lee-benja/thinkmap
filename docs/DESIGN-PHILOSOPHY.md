# 디자인 철학: 건조한 스타일 (Dry Style)

> 작성일: 2026-04-14

---

## 원칙

ThinkMap의 UI는 **건조하게** 간다. 내용이 말하게 하고, 장식은 빼는 방향.

### 하지 않는 것

- **폰트 크기 변경**: 섹션 헤더든 제목이든 본문과 동일한 크기. `h1`~`h3` 같은 타이포그래피 계층 없음
- **밑줄 / border-bottom**: 섹션 구분용 장식선 사용 안 함
- **장식적 배경**: 포커스, 호버 시 배경색 변화 최소화
- **특별한 섹션 스타일**: 업무일지 섹션 헤더에 별도 폰트/크기/색상 적용 안 함

### 하는 것

- **bold**: 섹션 제목 등 구분이 필요한 텍스트는 굵기로 구분 (worklogTemplate.js에서 bold mark 적용)
- **들여쓰기**: 토글 중첩으로 구조를 표현
- **기능적 레이아웃**: flex, gap, padding 등 배치에 필요한 CSS는 사용

### `blockType` 속성의 역할

`blockType: 'h2'`는 **메타데이터**이지 스타일 지시자가 아니다.

- CSS에서 `[data-block-type="h2"]`로 스타일을 적용하지 않음
- "이 토글이 섹션 헤더다"라는 의미 표시 용도
- 향후 섹션 단위 기능(드래그, 접기 등)을 위한 셀렉터로 활용 가능

### 양식(Template)과 스타일의 분리

업무일지의 "양식"은 **내용 구조**(어떤 섹션이 들어가는가)만 정의한다. 양식이 폰트 스타일이나 문서 장식을 추가하지 않는다.

```
양식 = 섹션 구성 (할 일, 전달사항, 마무리 기록)
양식 ≠ 스타일 (폰트 크기, 색상, 밑줄)
```
