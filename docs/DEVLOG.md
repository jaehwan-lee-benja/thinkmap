## 2026-07-04 — S1~S7 파도 + 데일리 권한/캘린더 통합

### 이번 판의 방식
worktree-per-session 으로 여러 작업을 병렬로 돌리고, "통합 세션" 하나가 git 머지·배포·프로덕션 마이그를 단일 담당했다. 워커는 코드·진단만, 커밋/머지/배포/마이그 적용은 통합 세션. 프로덕션 마이그는 예외 없이: SQL 제시 → supabase-guardian 검수 → 명시 승인 → 적용 → dry-run.

### 배포 완료(프로덕션 라이브)
- **데일리 기본수정** — 섹션색 새로고침 시 투명도 유실 수정 + 중복 blockId 블록 소실을 무손실로(재발급 + upsert revive). 중복키 실환경 재현 검증은 대기.
- **S1 토글/에디터 모바일 UX** — 핸들 메뉴 뎁스 + 들여쓰기/내어쓰기 큰 버튼 연속 조작 + 메뉴 가림 방지(flip) + 버블 ⚙블록설정. 최상단 타이핑 중 커서 튕김을 에코가드+selection 보존으로 해결.
- **S3 캘린더 통합** — 캘린더 2개(데일리 인덱스 + 시간박스)를 레이어드 단일 캘린더로. CalendarShell + 레이어(데일리를 월간셀/주헤더에 주입). 사이드바 1개로. 마이그 없음.
- **S7 편집 충돌** — "○○님이 수정했어요" 오탐 제거(탭별 ownWrites), 선택지 라벨 명확화, 덮어쓰기 전 스냅샷 → 원클릭 되돌리기(무손실).
- **S2 데일리 권한모델** — "섹션=공유 단위, 기본 마스터 전용, 공유 시 멤버 열람". 이월 시 섹션 색/접힘 풀림을 worklog_sections 마스터 저장·승계로 해결. 오늘 버튼 더블탭·아이패드 겹침 수정. → 마이그 2건 + Edge 재배포.
- **S5 직원 역할배치도** — 요일별 인원배치를 "이름붙은 여러 버전 + 별표(주배치)"로 격상(별표 버전이 빈 날짜 자동 시드). → 마이그 1건(신규 테이블 2 + RPC), 기존 16행 무손실 이전.
