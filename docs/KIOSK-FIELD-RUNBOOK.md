## 1. 기기별 세팅

로그인 계정은 **전부 같다**: `sarurufarm.partner@gmail.com` (Google 로그인).
※ 손님 폰만 로그인 없이 열린다.

| 기기 | 여는 주소 | 로그인 | 화면 |
|---|---|---|---|
| ① 고객 태블릿 (CS-273N, 세로) | `.../thinkmap/membership/` | 필요 | 손님이 번호 넣고 조회·참여·가입 |
| ② 직원 노트북 | `.../thinkmap/membership/?role=staff` | 필요 | 직원 조회 + 회원 검색 |
| ③ 카운터 스캔 (바코드 리더 붙은 PC) | `.../thinkmap/membership/?role=scan` | 필요 | 티켓 스캔 → 팝콘 제공 완료 |
| ④ 카운터 폰 (프린터 연결) | `.../thinkmap/membership/?role=printer` | 필요 | 인쇄 대기실(자동 인쇄) |
| ⑤ 손님 폰 | 키오스크 화면의 **QR을 찍으면 자동으로 열림** | 불필요 | 바코드 표시만 |
| ⑥ 영수증 모양 편집 (사장님) | `.../thinkmap/membership/?role=editor` | 필요 | 영수증 레이아웃 편집 |

### 1-1. 고객 태블릿 (①)
1. Fully Kiosk Browser 를 쓴다. 설정에서 **시작 주소(Start URL)** 를 위 ① 주소로 넣는다.
2. 처음 한 번만 Google 로그인 → `sarurufarm.partner@gmail.com`. 그 뒤엔 로그인 유지된다.
3. 화면은 **세로**로 둔다(세로 전용으로 맞춰져 있다).
4. 손님이 2분 동안 아무것도 안 만지면 자동으로 첫 화면으로 돌아간다. 마지막 15초는 안내가 뜬다.
   - 시간을 바꾸려면 주소 뒤에 `&idle=180`(초). `&idle=0` 이면 자동 복귀 끔.
   - 주소에 `?` 가 없으면 `?idle=180` 으로 쓴다.

### 1-2. 직원 노트북 (②) / 카운터 스캔 (③)
1. Chrome 에서 주소를 열고 로그인 → **북마크바에 추가**. 이름은 "멤버십-조회", "멤버십-스캔".
2. ③ 스캔 화면은 **입력칸을 클릭하지 않아도 자동으로 커서가 잡힌다.** 바코드를 그냥 쏘면 된다.
3. ③ 은 한글 상태로 두어도 된다(한글 입력기 상태에서도 읽히게 되어 있다).

### 1-3. 카운터 폰 (④)
1. Chrome 으로 ④ 주소를 열고 로그인.
2. **홈 화면에 추가**: Chrome 우측 위 ⋮ → "홈 화면에 추가" → 이름 "인쇄 대기실" → 추가.
3. RawBT(영수증 인쇄 앱)가 설치되어 있어야 하고, 프린터와 **미리 페어링**되어 있어야 한다.
4. 영업 중에는 이 화면을 **켜 둔다**(자동 인쇄는 이 화면이 열려 있을 때만 온다).
5. "자동 인쇄" 체크는 켜 둔다. 인쇄하는 순간에만 RawBT 로 잠깐 넘어갔다 돌아온다.
6. 음악(유튜브 뮤직)은 계속 나오는 것이 정상이다. **첫 인쇄 때 한 번만 확인**해 주세요. 끊기면 6장으로 보고.

### 1-4. 영수증 편집 (⑥) — 사장님만
- ★중요: 편집한 영수증 모양은 **편집한 그 기기에만 저장된다**(확인함).
- 실제 영수증을 바꾸려면 **인쇄하는 기기(카운터 폰)에서 편집·저장**해야 한다. 노트북에서 바꿔도 폰 영수증은 안 바뀐다.

## 2. 매일 여는 절차 / 닫는 절차

### 여는 절차 (3줄)
1. 고객 태블릿 켜기 → 첫 화면(소 로고 + 번호 입력)이 보이는지 확인.
2. 카운터 폰에서 "인쇄 대기실" 열기 → 빨간 경고 카드가 **없는지** 확인 → 프린터 전원·용지 확인.
3. 스캔 PC에서 스캔 화면 열기 → 아무 종이나 바코드 하나 쏴서 반응이 뜨는지 확인(안 뜨면 4장).

### 닫는 절차
1. 카운터 폰: 인쇄 대기실 닫고 화면 잠금.
2. 고객 태블릿: 화면이 **첫 화면**인지 확인(손님 정보가 남아 있으면 "처음으로" 누르고 끈다).
3. 스캔 PC: 화면 닫기. **로그아웃은 하지 않는다**(다음 날 다시 로그인해야 함).

## 3. 손님 응대 흐름

### 3-1. 기본 (손님이 직접)
1. 손님이 태블릿에 **전화번호 11자리** 입력 → [조회].
2. 회원이면 → "안녕하세요, OOO 회원님!" + 도장판이 뜬다.
3. [사르르 팝콘 이벤트 참여] 누름 → **참여권 번호**와 **QR**이 뜬다.
4. 손님에게 안내: "카운터에서 이 화면을 보여주시거나, QR을 폰으로 찍어 가세요."
5. 카운터: 손님 폰 바코드(또는 종이 영수증)를 **스캔** → 화면에 초록색 "유효 — 제공 가능" → **[팝콘 제공 완료]** 누르고 팝콘을 준다.
6. [다음 스캔] 을 눌러 다음 손님 준비.

### 3-2. 회원이 아닐 때
1. "아직 멤버십 회원이 아니세요" 카드가 뜬다 → [멤버십 가입하기] 안내.
2. 이름 · 전화번호 · **이메일** · 동의 체크가 모두 있어야 가입된다.
3. **이메일이 없는 손님은 직원이 처리**한다(화면에도 그렇게 안내된다).
4. 가입 완료(🎉) 화면이 떠야 진짜 가입이다. 빨간 글씨가 뜨면 번호를 다시 확인한다.

### 3-3. 어르신 · 손이 불편한 손님
- **원칙: 직원이 대신 눌러 드린다.**
- 방법 A(가장 확실): 직원이 **고객 태블릿에 직접** 번호를 입력해 조회·참여까지 눌러 준다.
- 방법 B: 직원 노트북(`?role=staff`)에서 조회하면 고객 태블릿에도 같이 뜬다.
  - 단 **실시간 스위치가 켜져 있을 때만** 된다(0-2·0-3 참고). 태블릿에 안 뜨면 바로 방법 A로 바꾼다.
- 종이 영수증을 원하시면 카운터 폰에서 자동으로 나온 영수증을 드린다.

### 3-4. 아이스크림(도장 10개)
- 도장이 다 차면 화면에 "🍦 아이스크림 N개 수령 가능"이 뜬다.
- **[수령] 버튼은 직원이 확인하고 누른다.** 누르는 즉시 차감된다 — 아이스크림을 실제로 드린 뒤에 누른다.

## 5. 절대 하면 안 되는 것

1. **개인 구글 계정으로 로그인하지 않는다.** 매장 계정(`sarurufarm.partner@gmail.com`)만 쓴다.
2. **손님 앞에서 "회원 리스트 확인하기"를 열지 않는다.** 다른 손님 정보가 보이는 화면이다. 직원 노트북에서, 손님 시야 밖에서만.
3. **손님 전화번호를 종이·메모장·카톡에 적지 않는다.** 필요하면 끝 4자리만.
4. **태블릿을 루팅하거나 임의로 앱을 설치하지 않는다.**
5. **팝콘/아이스크림을 먼저 주고 나중에 누르지 않는다.** 버튼을 누른 순간이 기록이다(아이스크림은 실제로 드린 뒤 누른다).
6. **"이미 회수됨" 티켓으로 두 번 주지 않는다.**
7. **로그아웃·계정 전환을 임의로 하지 않는다.** 다시 로그인해야 영업이 된다.

## 6. 연락 · 보고

문제가 생기면 **아래 4가지를 찍어서** 사장님께 보낸다.

1. **화면 사진** (오류 문구가 다 보이게, 잘라내지 말고).
2. **어느 기기인지** — 고객 태블릿 / 직원 노트북 / 스캔 PC / 카운터 폰 / 손님 폰.
3. **주소(URL)** — 주소창이 보이는 기기는 주소를 같이 찍는다. Fully Kiosk 라 주소창이 없으면 **"고객 태블릿"** 이라고만 적는다.
4. **시각** — 몇 시 몇 분에 생겼는지.

같이 적으면 좋은 것
- 참여권 **번호**(영문+숫자 12자리) — 있으면 추적이 된다.
- 손님 전화 **끝 4자리만**(전체 번호는 쓰지 않는다).
- 그때 몇 명이 줄 서 있었는지(동시 처리 문제인지 판단용).

보고하면서 **영업은 멈추지 않는다**
- 인쇄가 죽으면 → 참여권 **번호**를 손님께 보여드리고 스캔 화면에 수기 입력.
- 스캔이 죽으면 → 번호 수기 입력.
- 태블릿이 죽으면 → 직원 노트북(`?role=staff`)에서 조회해 응대.
- **번호가 정본이다. 종이와 QR은 편의일 뿐이다.**
