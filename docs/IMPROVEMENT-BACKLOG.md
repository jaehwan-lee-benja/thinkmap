# ThinkMap 개선 백로그

브랜치 매니저 세션이 유지하는 개선/버그 목록. **세션 안배(어떤 작업을 어느 브랜치/세션으로 묶을지) 계획**에 사용한다.

- 상태 표기: 🆕 backlog · 🔄 진행 중(브랜치) · ✅ 완료(main 머지) · 🚀 배포됨
- 심각도: 🔴 높음 · 🟠 중간 · 🟡 낮음 · ⚪ 미정
- 새 항목은 아래 "상세"에 추가하고, 표에 한 줄 요약을 더한다.

## 요약 표

| # | 영역 | 제목 | 심각도 | 상태 |
|---|------|------|--------|------|
| B-1 | 모바일/에디터 | 모바일에서 편집모드 진입(더블클릭) 안 됨 | ⚪ 미정 | 🆕 backlog |

## 상세

### B-1 · 모바일에서 편집모드 진입 안 됨
- **영역**: 모바일 / 에디터(편집모드 진입)
- **증상**: 더블클릭하면 편집모드로 들어가야 하는데, 모바일에서는 진입이 안 됨.
- **재현**: PC 개발자도구의 모바일 에뮬레이션으로 접근 시 재현됨.
- **심각도**: ⚪ 미정
- **원인 가설(미검증)**: 데스크톱 `dblclick` 이벤트가 모바일/터치 환경에서 안정적으로 발생하지 않음 → 터치용 더블탭(`touchend` 간격 감지) 처리가 따로 필요할 수 있음. 실제 코드 확인 필요.
- **제안 세션 묶음**: 모바일/터치 입력 개선 (실기기 또는 에뮬레이션 검증 필수)
- **상태**: 🆕 backlog
- **등록일**: 2026-06-21
