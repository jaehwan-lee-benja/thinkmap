## 상세

### B-1 · 모바일에서 편집모드 진입 안 됨
- **영역**: 모바일 / 에디터(편집모드 진입)
- **증상**: 더블클릭하면 편집모드로 들어가야 하는데, 모바일에서는 진입이 안 됨.
- **재현**: PC 개발자도구의 모바일 에뮬레이션으로 접근 시 재현됨.
- **심각도**: ⚪ 미정
- **원인 가설(미검증)**: 데스크톱 `dblclick` 이벤트가 모바일/터치 환경에서 안정적으로 발생하지 않음 → 터치용 더블탭(`touchend` 간격 감지) 처리가 따로 필요할 수 있음. 실제 코드 확인 필요.
- **제안 세션 묶음**: 모바일/터치 입력 개선 (실기기 또는 에뮬레이션 검증 필수)
- **상태**: 🆕 backlog
- **등록일**: 2026-06-21

### B-2 · 자리배치도 자동 채움 가드가 모달 재오픈 시 재발
- **영역**: 자리배치도(Roster) / 요일 인원배치 기본
- **증상**: 빈 날짜 자동 채움 가드가 모달 인스턴스(ref) 한정이라, 그날 인원을 일부러 0으로 비워둬도 모달을 닫았다 다시 열면 다시 자동으로 채워질 수 있음(`rows.length===0` 조건).
- **출처**: S4 spec-auditor 검수(W-1). 머지는 됐고 비차단 항목.
- **심각도**: 🟠 중간 (의도 확인 필요 — 의도면 노트, 아니면 "그날 비움" 상태를 명시 저장)
- **상태**: 🆕 backlog · **등록일**: 2026-06-21

### B-3 · 자리배치도 동시 오픈 시 중복 insert
- **영역**: 자리배치도(Roster) / 자동 채움 동시성
- **증상**: 두 사용자가 같은 빈 날짜를 동시에 열면 둘 다 `rows.length===0`을 통과해 중복 일괄 insert 가능(특히 member_id 없는 임시 인원은 unique 제약 무방비).
- **출처**: S4 spec-auditor 검수(W-4). 비차단.
- **심각도**: 🟡 낮음
- **상태**: 🆕 backlog · **등록일**: 2026-06-21
