# 토글/블록 복붙 개발 기준 (필독)

> **모든 세션에서 토글/블록 관련 코드를 수정하기 전에 이 문서를 반드시 확인할 것.**

---

## 핵심 원칙

ThinkMap의 모든 최상위 블록은 토글이다. 토글이 이 에디터의 기본 단위다.

---

## 절대 깨뜨리면 안 되는 기능

| 기능 | 설명 | 확인 방법 |
|------|------|----------|
| 넘버링 차단 | 토글 내부에서 ordered list 등 사용 불가 | 토글 안에서 넘버링 시도 → 적용 안 됨 |
| 여러 블록 동시 복붙 | 토글 안에서 여러 줄 붙여넣기 → 각각 형제 토글로 생성 | 3줄 텍스트 복사 → 토글 안에서 Cmd+V → 3개 토글 생성 |
| 멀티셀렉트 복사 | Cmd+클릭으로 여러 토글 선택 후 Cmd+C/V | 3개 토글 선택 → 복사 → 붙여넣기 → 3개 토글 삽입 |
| 토글→토글 복사 | 토글 블록 복사 후 붙여넣기 → 형제로 삽입 | 토글 복사 → 다른 토글 안에서 Cmd+V → 형제 레벨에 삽입 |
| 단일 텍스트 인라인 삽입 | 짧은 텍스트 복사 → 토글 안에서 커서 위치에 삽입 | "hello" 복사 → 토글 텍스트 중간에 Cmd+V → 인라인 삽입 |

## 중첩 문제의 근본 원인

```
content: '(paragraph | toggle)+'   ← 토글이 paragraph와 toggle을 자식으로 허용
defining: true                      ← ProseMirror에게 "콘텐츠 경계"로 인식시킴
```

ProseMirror의 기본 paste fitting 알고리즘이 `defining: true` 노드를 만나면,
slice의 내용을 그 **내부에** 맞추려고 시도한다.
명시적 핸들러(`handlePaste`, `transformPasted`)가 개입하지 못하는 경로에서 이 문제가 발생.

---

## 수정 원칙

1. **명시적 핸들러(handlePaste, transformPasted 등)는 건드리지 않는다** — 이미 잘 작동하는 경로
2. **ProseMirror 기본 경로에서 발생하는 중첩만 차단한다** — `defining` 속성 또는 `transformPasted` 범위 조정
3. **스키마(`content`, `group`)는 변경하지 않는다** — 넘버링 차단 등 다른 제약이 이 스키마에 의존

---

## 수정 전 체크리스트

코드 변경 후 아래 시나리오를 **모두** 수동 테스트할 것:

- [ ] 토글 안에서 텍스트 1줄 Cmd+V → 인라인 삽입 (토글 중첩 없음)
- [ ] 토글 안에서 텍스트 3줄 Cmd+V → 형제 토글 3개 생성 (중첩 없음)
- [ ] 토글 블록 복사 → 토글 안에서 Cmd+V → 형제로 삽입 (중첩 없음)
- [ ] 멀티셀렉트 3개 → Cmd+C → Cmd+V → 형제 3개 삽입
- [ ] 토글 안에서 넘버링 시도 → 적용 안 됨 (스키마 제약 유지)
- [ ] 외부(브라우저 등)에서 복사한 텍스트 → 토글 안에서 Cmd+V → 정상 삽입
